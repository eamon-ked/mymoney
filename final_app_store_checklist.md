# Final App Store Submission Checklist

## ✅ Pre-Submission Requirements

### **App Store Connect Setup**
- [ ] Apple Developer Account active ($99/year)
- [ ] App Store Connect access
- [ ] App created in App Store Connect
- [ ] Bundle ID: `nokael.PersonalFinanceApp`
- [ ] App name: "Nokael Money"

### **App Build**
- [ ] App builds successfully in Release mode
- [ ] App archived for distribution
- [ ] Build uploaded to App Store Connect
- [ ] Build processing completed

### **App Information**
- [ ] App name: "Nokael Money"
- [ ] Subtitle: "Personal Finance Manager"
- [ ] Category: Productivity
- [ ] Age rating questionnaire completed
- [ ] Content rights confirmed

### **Legal Documents**
- [ ] Privacy Policy URL: `https://mymoney-legal-docs.pages.dev/privacy-policy.html`

- [ ] Legal documents hosted and accessible

### **App Store Listing**
- [ ] App description written
- [ ] Keywords added (finance, money, budget, etc.)
- [ ] Promotional text (170 chars max)
- [ ] What's New in This Version

### **Screenshots**
- [ ] iPhone 6.7" screenshots (1290 x 2796)

### **App Icon**
- [ ] 1024x1024 PNG icon uploaded
- [ ] Icon meets Apple's design guidelines
- [ ] No transparency or alpha channels

### **Technical Requirements**
- [ ] App supports iOS 17.6+
- [ ] No hardcoded secrets in code
- [ ] Privacy usage descriptions added
- [ ] Account deletion functionality working
- [ ] App doesn't crash on launch
- [ ] All features work as expected

### **Testing**
- [ ] Tested on multiple devices
- [ ] Tested account creation/deletion
- [ ] Tested all main features
- [ ] Tested offline functionality
- [ ] Tested sync functionality

### **Final Submission**
- [ ] All required fields completed
- [ ] Build selected for submission
- [ ] Screenshots uploaded
- [ ] App description and keywords added
- [ ] Legal documents linked
- [ ] Ready to submit for review

## 🚀 Submission Steps

1. **Archive app** in Xcode (Product → Archive)
2. **Upload build** to App Store Connect
3. **Complete app information** in App Store Connect
4. **Add screenshots** for all required device sizes
5. **Write app description** and add keywords
6. **Link legal documents**
7. **Submit for review**
