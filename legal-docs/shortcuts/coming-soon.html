The ready-made shortcut isn't available right now. You can set the automation up by hand in a minute:

  1. Open Shortcuts, tap Automation, then +, and choose Message.
  2. Add the filter Message contains your currency code (for example USD or GBP), choose Run Immediately.
  3. Add “Read Bank Message” from Nokael Money.
  4. Set Message to Shortcut Input, and Sender to Shortcut Input › Sender.

The same steps are in Nokael Money under More › Siri & automatic capture.
